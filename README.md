# IdleOn Lab Route Planner

Небольшой браузерный помощник для планирования подключения бонусов Laboratory в World 4. Принимает raw JSON или имя опубликованного профиля IdleOn Efficiency; данные не передаются на собственный сервер.

## Статус

Это ранний прототип интерфейса, не точный симулятор игровой лаборатории. В текущей версии перечислены 18 бонусов с Idleon Toolbox и построена порядковая схема mainframe. Фактические координаты нод в игровых пикселях пока не сверены с клиентским layout, а импортированные из Raw JSON уровни/ширина/дальность нельзя считать надёжными до проверки ключей конкретной версии экспорта. Параметры можно поправить вручную. Поэтому результат сейчас является эвристической оценкой, а не готовой инструкцией для перестановки персонажей.

Игра, поставленная в локальной Steam-библиотеке, содержит упакованные ресурсы Electron, но не исходный проект, в котором можно однозначно подтвердить формулы и координаты mainframe. Репозиторий не включает игровые файлы или игровые изображения.

## Запуск

Откройте `index.html` в современном браузере. Для загрузки профиля по имени потребуется доступ к `cdn.idleonefficiency.com`; если браузер блокирует запрос политикой CORS, вставьте raw JSON из IdleOn Efficiency.
